# K24 — the sign ops (`fneg`, `fabs`, `copysign`) and `fmin` / `fmax` at `f64`

**Module** M38 `fmisc`, first half — `src/kernels/fmisc.h`, `fmisc_int.h`,
`fmisc_sign.c`, `fmisc_rows.c`, `fmisc_step.c`, `fmisc_minmax.c`. **Bead**
`opcode_quantum_operations-9ve.27.1` (parent `9ve.27`). The rounding half of M38
(`fround*`, K25) is a sibling bead and is not described here.
**Upstream** Bennett.jl at the pin in `third_party/bennett/COMMIT` (its `commit:` line,
`980805de85314b3da7ac25cf6454b56566f8e609`).

K24 is two shapes behind one header, split on PRD-v2 §5's recorded seam **SIGN OPS ↔
EVERYTHING ELSE**. The sign ops are one upstream block each and have no scratch; `fmin` /
`fmax` are row tables over five other modules' step blocks, sandwiched.

`soft_fminimum` / `soft_fmaximum` (`fmin.jl:29-76`) are in the same file and are
**NaN-propagating**; `llvm.minnum` routes to `soft_fmin` (PRD-v2 §7.7). `soft_minimumnum` /

**D8 audit (PRD-v2 §7.6):** `fmin.jl` has eight shifts, all `>> 52`; `fneg.jl` none. No
variable shift, so no D8 exposure.

## 2. Construction

### 2.1 Sign ops — one block each, straight onto `dst` (D-K24-1)

| op | upstream block | slots | per-lane gates before folding |
|---|---|---:|---|
| `fneg` | `lower_xor!(a, SIGN)` (`arith.jl:284-290`) | 128 | `CX(a[i]→dst[i])`, `CX(K[i]→dst[i])` |
| `fabs` | view `a & ABS` + `_emit_copy_out!` (`arith.jl:89-96`) | 64 | `CX(view[i]→dst[i])` |
| `copysign` | views `x & ABS`, `y & SIGN` + `lower_or!` (`arith.jl:274-282`) | 192 | `CX(m[i])`, `CX(s[i])`, `CCX(m[i], s[i])` |

**D-K24-1 — no sandwich.** Upstream's block allocates a fresh result wire and writes it; a
fresh zero `dst` IS that wire, and `dst ^= f(a)` twice is zero, so the kernel is K1/K3's
shape (`src/kernels/bitwise.c`) rather than Bennett-in-the-small: there is no scratch for
Rule 2 to return. The sandwich would double every count for no ancilla.

**D-K24-2 — no `_eval` and no short-circuit for the sign ops.** On all-classical operands
every slot is a constant-controlled X/CX onto a constant `dst` lane, which the §3 fold table
rewrites in place: zero gates, zero qubits, with nothing allocated (R9's hazard is
pre-materialisation, and there is none). A C `_eval` would be dead code.

**Zero Toffoli at every mask**: `copysign`'s `lower_or!` Toffoli has one control from each of
two DISJOINT views, so on every lane one control is a constant ZERO.

### 2.2 `fmin` / `fmax` — 17 rows each, in source order

| row | op | operands | source |
|---:|---|---|---|
| 0 | CLASS_NAN | A | `:93` `a_nan` |
| 1 | CLASS_NAN | B | `:94` `b_nan` |
| 2 | AND1 | 0, 1 | `:95` `both_nan` |
| 3 | EQ | ABS_A, 0 | `:97` raw `abs_a != 0` |
| 4 | NOT1 | 3 | `:97` `abs_a == 0` |
| 5 | EQ | ABS_B, 0 | `:97` |
| 6 | NOT1 | 5 | `:97` `abs_b == 0` |
| 7 | AND1 | 4, 6 | `:97` `both_zero` |
| 8 | EQ | SGN_A, 0 | `:98` `a_neg` (the source spells `!=`: raw wire, no not1) |
| 9 | FCMP_OLT | A, B (**fmax: B, A**) | `:100` / `:128` `soft_fcmp_olt` |
| 10 | EQ | row 9 (zext), 0 | `:100` `!= UInt64(0)` |
| 11 | MUX | 10, A, B | `:101` `base` |
| 12 | MUX | 8, A, B (**fmax: 8, B, A**) | `:102` / `:130` inner `ifelse` |
| 13 | MUX | 7, 12, 11 | `:102` `base` |
| 14 | MUX | 1, A, 13 | `:104` inner `ifelse(b_nan, a, base)` |
| 15 | MUX | 0, B, 14 | `:104` `res` |
| 16 | MUX | 2, K_QNAN, 15 | `:105` the canonical NaN |

The views (`:87-92`, `:98`'s mask) cost nothing (PRD-v2 §7.3 as amended); `SGN_A` keeps lane
63 IN PLACE — it is an `and`, not `>> 63`. Every `(e == 0x7FF) & (f != 0)` is M31's
`CQ_FP_IS_NAN` block, as in K18 (D-K18-8). `soft_fcmp_olt` is M36's 24-row `B_OLT`
program reached through `cq_fcmp_step`, never `cq_kernel_fcmp_olt` (cq_sandwich refuses
nesting). `soft_fcmp_olt(a,b) != 0` is TWO occurrences — the call and the `!=` — so the flag
is zero-extended to the Julia type's width and fed to a 64-lane `eq` against 0 (§7.2).

**fmax differs from fmin in exactly rows 9 and 12**, and both differences are operand
ORDER — invisible to every count, palindrome and pool check; only L1 sees them.

### 2.3 Layout, copy-out, I6

One flat region, prefix-summed over rows; each row's bits are asked of its module
(`cq_fp_class_region`, `cq_eq_region(64)`, `cq_fcmp_region`, `cq_mux_region(64)`; one bit per
`not1`/`and1`). The copy-out is 64 CX from row 16's `r` into `dst`. Every target in the
compute half is a bit of the region; the rails, views and constants reach the emitter only
as `const` controls, so I6(a) holds by construction.

## 3. Seams — RECORDED IN ADVANCE (Rule 12)

1. **SIGN OPS ↔ EVERYTHING ELSE** (PRD-v2 §5): `fmisc_sign.c` against the rest. Taken.
2. **ROW TABLES ↔ STEP MACHINE** (D-K18-7, every fp module since): `fmisc_rows.c` holds the
   two tables and their accessors and nothing else. Taken.
3. **LAYOUT-AND-OPERANDS ↔ DISPATCH-AND-SURFACE** (D-K23-10): `fmisc_step.c` (costs,
   layout, operand resolution, the one-gate dispatch, the block API) against
   `fmisc_minmax.c` (the two Rule 7 kernels). Taken.
4. **`_eval` ↔ THE CIRCUIT**: recorded, NOT taken — `fmisc_minmax.c` measured 73 of 300.
5. **COSTS-AND-LAYOUT ↔ OPERAND RESOLUTION** (M33's fourth): recorded, NOT taken —
   `fmisc_step.c` measured 220 of 300 (tools/check_loc.sh, 2026-09-24).

## 4. Measured — Release, 2026-09-24, all-quantum on every source, W = 64

Instrument: `cq_kd_measure` (tests/test_kernel_fmisc.c `l4_goldens`) and
`each_program_is_the_sum_of_its_blocks`'s printed line; pinned in
`tests/goldens/fmisc.counts`, taken with `CQOPS_UPDATE_GOLDENS=1` on a new file.

| kernel | rows | slots | scratch bits | forward (X, CX, CCX) | `_unc` (X, CX, CCX) | dst qubits |
|---|---:|---:|---:|---|---|---:|
| `fneg` | 1 block | 128 | 0 | (1, 64, 0) | (1, 64, 0) | 64 |
| `fabs` | view + copy | 64 | 0 | (0, 63, 0) | (0, 63, 0) | **63** |
| `copysign` | 2 views + 1 block | 192 | 0 | (0, 64, 0) | (0, 64, 0) | 64 |
| `fmin` | 17 | 7,813 | 3,408 | (532, 8,228, 3,446) | (532, 8,228, 3,446) | 64 |
| `fmax` | 17 | 7,813 | 3,408 | (532, 8,228, 3,446) | (532, 8,228, 3,446) | 64 |

`fmin` / `fmax` slots = 2·637 (class) + 4·317 (`eq`) + 2·2 (`not1`) + 2·1 (`and1`) +
`cq_fcmp_steps(B_OLT)` + 6·256 (`mux`); bits likewise over each module's `_region`. Both
identities are asserted with every term ASKED of its module. Forward and `_unc` agree here
because the mask is the D6 fixed point; that is an observation, never an assertion (Rule 14).

**`fabs` owns 63 qubits, not 64** (D-K24-3): lane 63 is `a[63] & 0`, a constant-ZERO view
lane, so its copy-out CNOT folds and that `dst` lane is never materialised. The peak equals
the owned count for all three sign ops — no scratch at all.

**Zero Toffoli** for all three sign ops at the all-quantum mask AND at every mask pair of
`cq_bk_fixed_pairs(64)` (asserted, not narrated).

## 5. Decisions not written elsewhere, and what the battery measured

- **D-K24-1 / D-K24-2** (§2.1): sign ops unsandwiched, no `_eval`.
- **D-K24-3**: `fabs`'s `dst` owns 63 qubits; `dst_ownership_and_the_scratch_high_water_mark`
  pins it.
- **D-K24-4 — the circuit anchor set is EXPLICIT**, eight rows per shape named for the
  neighbour each separates, not `cq_fp_representative_*_index` over the generic table (whose
  picks — +0/+0, +Inf/+Inf, a tie-to-even pair — separate none of `fmin`'s rows from
  `fminimum`'s). The complete classical table is generic + circuit set.
- **D-K24-5 — an sNaN against a number returns the number, bit-exact**, per the docstring
  (`fmin.jl:81-84`) and `llvm.minnum`; IEEE 754-2008's signalling exception is not modelled.
  The oracle says so and the anchors carry an sNaN in each position.
- **Non-64 `W`**: a hard error in both configurations for all five (M40/M39's posture;
  upstream's own `llvm.minnum` arm refuses non-64).

**Provocation battery** (Release, then the 20 guard deletions again in Debug; every mutant
restored with `cp` + `touch`, sources md5-checked afterwards). 50 mutants compiled; every
one reddened at least one case except the one equivalent below. Notable single detectors:

| mutant | the ONLY case(s) that went red |
|---|---|
| `k->off` dropped in the prefix walk | `two_programs_in_one_region_do_not_collide` |
| `B_OLT`'s region +1 | `each_program_is_the_sum_of_its_blocks` |
| `a & SIGN` spelled `a >> 63` (value- and kind-preserving) | `the_operands_are_wired_lane_for_lane` — added AFTER this mutant survived every other case |
| `abs_b` view wired to `a` | `the_operands_are_wired_lane_for_lane` until the circuit anchor `(+0, 2)` replaced `(1, 2)`; now also L1 and the named cells |
| all-classical short-circuit ignores the program | `l1_sweep`, `controlled` |

**Equivalent mutant, recorded rather than chased:** exchanging an `eq` block's two operands.
Every `eq` in `fmin.jl` compares against the constant 0, whose lanes fold, so the emitted
stream is byte-identical.

**Masking found by the battery (Release):** the four operand-resolution refusals mask each
other — a deleted `op64` range check falls through to `cq_fx_flag_of`'s, and a deleted
`flag_of` range check reads `rows[-1]` and dies in `cq_fx_rail`. Each death case now bans its
siblings' sentences (tests/CMakeLists.txt group 6).

## 6. Tests and oracles

L1's oracle is `tests/support/fmiscref.c`, written from IEEE 754 minNum/maxNum plus the two
rules the docstring adds (both-NaN → canonical `0x7FF8000000000000`; ±0 → −0 for min, +0 for
max), using the host `<` for the ordered case — never a second transcription of `fmin.jl`.
The sign ops' oracle is host bit arithmetic.

**Width.** Every kernel refuses `W != 64` in both configurations (upstream's own
`llvm.minnum` arm refuses non-64 at `instructions.jl:5117-5120`).
