# K27 — integer intrinsics `abs`, `smin`, `smax`, `umin`, `umax` (M42 `iminmax`)

**Bennett source:** `third_party/bennett/src/extract/instructions.jl` lines 4782-4825 (pinned
commit 980805de85314b3da7ac25cf6454b56566f8e609). There is **no** `lower_umax!` / `lower_abs!`:
the extractor expands each intrinsic into ordinary IR, and each IR instruction is lowered by a
function libcqops has already ported:

| IR instruction | Upstream lowering | libcqops step block |
|---|---|---|
| `IRICmp :uge / :ule` | `lower_icmp!` → `lower_ult!` (`src/lowering/arith.jl:409-418`, `:449-463`) | M16 `cq_ult_step` (K09 §2.2) |
| `IRICmp :sge / :sle` | `lower_icmp!` → `lower_slt!` (`arith.jl:409-418`, `:465-472`) | M16 `cq_slt_step` (K09 §8) |
| `IRSelect` | `lower_select!` → `lower_mux!` (`arith.jl:516-519`, `:522-532`) | M17 `cq_mux_step` (K10) |
| `IRBinOp :sub` | `lower_binop!` → `lower_sub!` (`arith.jl:215`; `src/adder.jl:149-172`) | M14 `cq_sub_step` (K07) |

**libcqops module:** M42 — `src/kernels/iminmax.h`, `src/kernels/iminmax_step.c` (the block),
`src/kernels/iminmax.c` (the kernels). PRD-v2 §7.14 makes this a **v1-shaped integer** bead,
not fp. Bead `9ve.29.2` (parent `9ve.29`). Kernels only: no `shim/` wiring in this bead.

**Clean or sandwich:** **sandwich.** Every block composed is dirty by design (`lower_ult!`
leaves `nb`/carry/`axnb`, `lower_slt!` adds `af`/`bf`, `lower_sub!` leaves `~b` and the carry
chain, `lower_mux!` leaves `diff`), and libcqops has no global wrap, so Bennett-in-the-small:
one `cq_sandwich` per call — compute (all rows), `W` copy-out CNOTs from the mux row's `r`,
compute reversed.

### 1.1 The four predicates, resolved through OUR M16 table

`lower_icmp!` (`arith.jl:409-418`): `uge = not1(ult(a,b))`, `ule = not1(ult(b,a))`,
`sge = not1(slt(a,b))`, `sle = not1(slt(b,a))`. M16 folds the `not1` into the copy-out (K09 §5
delta 2): the raw flag of `ult(a,b)` is `carry[W]` = `a >=u b`, and of `slt(a,b)` is
`cq_slt_flag` = `a >=s b`. So, read off `src/kernels/cmp.c`'s own ten-row table:

| op | predicate | block | operands | SWAP | INVERT |
|---|---|---|---|---|---|
| umax | `uge` | ult | (a, b) | no | **no** |
| umin | `ule` | ult | (b, a) | **yes** | **no** |
| smax | `sge` | slt | (a, b) | no | **no** |
| smin | `sle` | slt | (b, a) | **yes** | **no** |
| abs  | `sge(x, 0)` | slt | (x, 0) | no | **no** |

**All five compares are in the KEEP set** — none of M16's five inverting predicates (`eq, ult,
ugt, slt, sgt`) is reached, so no copy-out `X` is owed. Two of the four min/max predicates swap.
The select is always `select(cmp, ops[1], ops[2])` — the **mux arms are never swapped**, only
the compare's operands are.

**Tie** (`a == b`): the compare is true, the mux selects `a` (`ops[1]`). Irrelevant to the value.

### 1.2 The constant `0` of `abs`

`iconst(0)` appears twice (the `sub`'s minuend and the `sge`'s second operand). Per PRD-v2 §7.3
it is a **source**, never scratch: `IMM_ZERO`, a `static const cq_bit[CQ_REG_WIDTH_MAX]` of
`CQ_BIT_ZERO`. It is only ever a control, so every gate it reaches folds at every mask: the
`CX(a[i], d[i])` of every ripple lane and the `CCX(a[i], nb[i], c[i+1])` of every lane but the
top one in `sub` (its minuend `a` is the `0`), and the `W` `CX(b[i], bf[i])` copies in `slt`
(its second operand is the `0`). The complement copies of `sub` read `x` and do not fold. **Hence `abs` is width-capped at `CQ_REG_WIDTH_MAX`** (the
array's length); registers cannot exceed it anyway.

`abs(INT_MIN) == INT_MIN`: `sub(0, INT_MIN)` wraps. That is LLVM's `llvm.abs(x, false)` — the
total function `intrinsic_table.yaml` says the ABI lowers (its `is_int_min_poison` immarg is a
constant dropped at lowering). Pinned by the anchors (§6).

## 2. Gate sequence as indexed pseudo-code

One block per IR instruction, in IR order, flat in one region at `off`; every gate is one step
of a sibling module's step function (`iminmax_step.c` emits nothing itself).

```
umax/umin/smax/smin (n = C + 4W):
  s in [0, C)        cmp block step s      C = cq_ult_steps(W) = 6W+1  (u*)
                                           C = cq_slt_steps(W) = 8W+3  (s*)
  s in [C, C+4W)     cq_mux_step(cond = flag, t = a, f = b, r, d; s - C)
abs (n = S + T + 4W):
  s in [0, S)        cq_sub_step(a = 0, b = x; s)          S = cq_sub_steps(W) = 7W-1
  s in [S, S+T)      cq_slt_step(x, 0; s - S)              T = cq_slt_steps(W) = 8W+3
  s in [S+T, n)      cq_mux_step(cond = slt flag, t = x, f = sub's d; s - S - T)
copy-out i in [0,W): CX(r[i], dst[i])
```

Layout (row by row, sizes asked of each module): min/max `[ult 3W+1 | slt 5W+1][r W][d W]`;
abs `[sub: nb W, d W, c W][slt: af, bf, nb, carry W+1, axnb][r][d]`.

**I6:** every target is a sibling block's scratch span inside the region; `a`, `b`, `0` and
the earlier rows' outputs (`flag`, sub's `d`) reach the emitter only as `const` controls.

### 3.2 The kernels — forward and `_unc` identical at this mask

| kernel | X | CX | CCX | total | scratch qubits (peak = W + scratch) |
|---|---|---|---|---|---|
| umax, umin | 2W+2 | 13W | 6W | 21W+2 | 5W+1 |
| smax, smin | 2W+6 | 17W | 6W | 25W+6 | 7W+1 |
| abs | 4W+8 | 21W | 8W−2 | 33W+6 | 10W+1 |

`umax`/`umin` and `smax`/`smin` are **identical in cost** — the swap is argument order. This
is why only L1 can tell them apart.

Evaluated (these literals are asserted in `the_closed_forms_in_k27_match_what_is_emitted`):

| | W=1 | W=8 | W=16 | W=32 | W=64 |
|---|---|---|---|---|---|

| s* | (8, 17, 6) | (22, 136, 48) | (38, 272, 96) | (70, 544, 192) | (134, 1088, 384) |

**Slots vs gates.** For min/max every slot emits (no constant). For abs the constant folds
`W` (sub's `a`-CX) + `W−1` (sub's `a`-CCX) + `W` (slt's `b`-copy) slots at every mask, so
`abs` compute = `19W+2` slots but `16W+3` gates. Asserted (`<`), not narrated.

## 5. Deltas from upstream

1. **The `not1` of `uge/ule/sge/sle` is folded** into reading the raw flag — M16's own delta 2,
   inherited. Upstream emits `ult`'s 2-gate result tail plus `not1`'s 2 gates per compare.
2. **Constants are sources** (PRD-v2 §7.3), not `resolve!`d wires: the `0` of `abs` folds.
3. **Bennett-in-the-small** instead of the global wrap: 2× compute + `W` copy-out.
4. **R9 classical short-circuit** at the kernel entry (all operands constant → the value is
   computed lane by lane in C and XORed into `dst` through `cq_emit_x`; 0 gates / 0 qubits into
   a constant `dst`). Same shape as M16's `const_raw` and M14's `fold_constant`.

## 6. Tests and anchors

L1's oracle is packed `uint64_t` with **explicit sign extension** and C's comparison operators
(`tests/test_kernel_iminmax.c`), sharing nothing with the circuit. Anchors (forced at the
all-classical and both mixed rows by the sampler, and at the all-quantum row by
`the_anchors_at_the_all_quantum_mask`):

- min/max: `(5,5)` tie; `(INT_MIN, INT_MAX)` and mirror; `(-1, 0)` and `(0, -1)` — **the
  smin/umin separator**; `(INT_MIN, 0)`.
- abs: `INT_MIN` (wraps), `0`, `-1`, `1`, `INT_MAX`, `INT_MIN+1`.

`the_anchors_separate_each_op_from_its_neighbour` asserts, reading no kernel, that every
neighbour pair (smin/umin, smax/umax, umin/umax, smin/smax, abs/identity for W ≥ 2) disagrees on
at least one anchor at every width.

## 8. Guards (all hard errors in both configurations)

| guard | message (`FATAL: kernel: …`) | death case(s) |
|---|---|---|
| D7a (kernel.h) | `D7a — dst overlaps a source` | `umax_dst_aliases_a_classical_source`, `abs_dst_aliases_its_source` |
| D7b (kernel.h) | `D7b — two sources overlap` | `smin_the_two_sources_are_the_same_register` |
| unknown op | `iminmax: unknown op` | `imm_steps_unknown_op_past_the_end`, `_negative` |
| W ≤ 0 | `iminmax: width is not positive` | `imm_steps_zero_width`, `imm_region_zero_width` |
| abs cap | `iminmax: abs width above CQ_REG_WIDTH_MAX` | `abs_wider_than_the_register_cap`, `imm_steps_abs_above_the_cap` |
| step index | `iminmax: step index outside` | `imm_step_index_past_the_end`, `_negative` |
| region fit | `iminmax: the block's region does not fit` | `imm_step_region_does_not_fit`, `imm_step_block_has_no_scratch` |

`cq_mux_step` has **no range guard**, so the step-index check is the only thing between an
off-by-one and a wild select lane. A negative index lands in the compare row, whose own `ult:`
guard fires one layer down — forbidden by regex so the case cannot pass on it. The W ≤ 0 cases
are masked from above by `cq_kernel_check_n` and from below by each sibling's identical width
guard (`ult:`/`slt:`/`sub:`/`mux:` — forbidden).
