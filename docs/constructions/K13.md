# K13 — QROM read at a quantum index (`dst ^= mem[idx]`)

**Bennett source:** `third_party/bennett/src/qrom.jl` lines 41-133 (`emit_qrom!` 41-83, `_qrom_tree!` 87-133) and the dispatch helper's index truncation at 165-176 (pinned commit 980805de85314b3da7ac25cf6454b56566f8e609)
**libcqops module:** M29 `kernels/qrom.[ch]` — v1.2, PRD §15 D24, plan §0.6, Step 27 (2026-09-02)
**Clean or sandwich:** **sandwich** — Bennett's tree is self-cleaning by a hand-written per-node uncompute; here the tree is the compute half of `cq_sandwich` and its reversal is structural (Rule 8). The fan-out is the copyout.

> **What is ported and what is not.** Bennett's QROM reads a COMPILE-TIME CONSTANT table:
> the leaf fan-out is a data-dependent CNOT from the leaf flag into each output bit whose
> constant is 1. Our cells are RAILS, so the fan-out is a Toffoli per (cell, lane),
> `CCX(leaf_j, cell_j[i], dst[i])`, and the §3 fold table turns a constant cell lane back
> into Bennett's gate: a ZERO lane emits nothing, a ONE lane emits `CX(leaf_j, dst[i])`. On
> a memset-0 array the port IS `emit_qrom!` gate for gate. The tree is ported verbatim in
> its gates and its order within a node; what changes is its SCHEDULE (§5 delta 1).

## 1. Julia source excerpt

Verbatim, `third_party/bennett/src/qrom.jl` lines 69-133 (the L == 1 branch, the root, and
the recursive walk):

```julia
    if L == 1
        # Degenerate: no index, just CNOT the single word directly onto output.
        # No flag needed — the single data word is always selected.
        word = data[1]
        for bit in 0:W-1
            if (word >> bit) & 1 == 1
                # Constant-1 output bit: apply NOT to the (zero) output wire.
                push!(gates, NOTGate(data_out[bit + 1]))
            end
        end
        return data_out
    end

    # Allocate the root control flag and initialize it to 1 (the root is always active).
    root_flag = allocate!(wa, 1)[1]
    push!(gates, NOTGate(root_flag))

    # Recursive unary iteration: walk the binary tree depth-first. At each
    # internal node we allocate two child flags (left/right), compute them
    # from the parent flag and the index bit, recurse, then uncompute.
    _qrom_tree!(gates, wa, data, data_out, idx_wires, root_flag, 0, L, n, W)

    # Uncompute root flag (reverse the initial NOT).
    push!(gates, NOTGate(root_flag))

    return data_out
end

# Depth-first walk of the binary tree. `parent_flag` is 1 iff idx ∈ [lo, hi).
# `bit_level` is the idx bit used to split this range (n-1 at root, 0 at leaves).
function _qrom_tree!(gates::Vector{ReversibleGate}, wa::WireAllocator,
                     data::Vector{UInt64}, data_out::Vector{Int},
                     idx_wires::Vector{Int}, parent_flag::Int,
                     lo::Int, hi::Int, bit_level::Int, W::Int)
    if hi - lo == 1
        # Leaf: fan parent_flag out to data_out via CNOTs per bit of data[lo+1]
        word = data[lo + 1]
        @inbounds for bit in 0:W-1
            if (word >> bit) & 1 == 1
                push!(gates, CNOTGate(parent_flag, data_out[bit + 1]))
            end
        end
        return
    end

    # Internal node: split [lo, hi) at midpoint using idx bit (bit_level - 1).
    mid = (lo + hi) >> 1
    idx_bit_wire = idx_wires[bit_level]  # idx bit (bit_level-1) is at 1-based index bit_level

    # right_flag = parent_flag AND idx_bit  (1 Toffoli)
    right_flag = allocate!(wa, 1)[1]
    push!(gates, ToffoliGate(parent_flag, idx_bit_wire, right_flag))

    # left_flag = parent_flag AND (NOT idx_bit) = parent_flag XOR right_flag
    # Implemented as: left_flag ← 0; CNOT(parent, left); CNOT(right, left).
    left_flag = allocate!(wa, 1)[1]
    push!(gates, CNOTGate(parent_flag, left_flag))
    push!(gates, CNOTGate(right_flag, left_flag))

    # Recurse — left subtree first, then right (DFS; order doesn't affect correctness).
    _qrom_tree!(gates, wa, data, data_out, idx_wires, left_flag, lo, mid, bit_level - 1, W)
    _qrom_tree!(gates, wa, data, data_out, idx_wires, right_flag, mid, hi, bit_level - 1, W)

    # Uncompute flags (reverse the three compute gates, self-inverse).
    push!(gates, CNOTGate(right_flag, left_flag))
    push!(gates, CNOTGate(parent_flag, left_flag))
    push!(gates, ToffoliGate(parent_flag, idx_bit_wire, right_flag))

    # After uncomputation both ancilla wires are zero; return them to the pool
    # so subsequent allocations reuse them (keeps wire count at O(log L) peak).
    free!(wa, [left_flag, right_flag])
    return
end
```

## 2. Gate sequence as indexed pseudo-code

Let `count` be the cell count, `n = ⌈log₂ count⌉` (0 when `count == 1`), `Lp = 2^n`, `W`
the cell width. The tree's flags live in ONE scratch region of `2·Lp − 1` bits in HEAP
ORDER: node `k` has children `2k+1` (left, index bit clear) and `2k+2` (right, index bit
set); the root is node 0; leaf `j` is node `Lp − 1 + j`. A node at depth `d` splits on
index lane `n − 1 − d` — the root on the MSB of the truncated index, exactly Bennett's
`bit_level` counting down from `n`.

### 2.1 The tree block (exported; K14 shares it)

`n_compute = 1 + 3·(Lp − 1)` steps, one gate each (bd ckd.14a — one INVOLUTION per step):

```
step 0:                       X(flag[0])                              -- root := 1
step u = 1 + 3k + phase, for internal node k = 0 .. Lp-2 (BFS = heap order,
                             so every parent precedes its children), lane b = n-1-depth(k):
  phase 0:                    CCX(flag[k], idx[b], flag[2k+2])       -- right := parent ∧ idx_b
  phase 1:                    CX (flag[k],         flag[2k+1])       -- left  := parent
  phase 2:                    CX (flag[2k+2],      flag[2k+1])       -- left  ^= right  (= parent ∧ ¬idx_b)
```

Bennett's node emits exactly these three gates in exactly this order (`qrom.jl:110-118`);
what differs is that Bennett recurses between a node's compute and its uncompute, and the
driver instead runs every node's compute, then the copyout, then every node's compute again
in reverse step order — which IS Bennett's per-node uncompute (`:127-129`, "reverse the
three compute gates, self-inverse"), applied to the whole tree at once.

### 2.2 The copyout (K13's own)

`n_copyout = count · W` steps, `s = j·W + i`:

```
  CCX(flag[Lp-1+j], cell_j[i], dst[i])          -- dst ^= leaf_j ∧ cell_j[i]
```

Leaves `j ≥ count` (the padding) own no cell and emit nothing. `dst` is outside scratch and
the driver disarms I6's extent for the copyout, as for every sandwich kernel.

### 2.3 `count == 1`

Bennett's L == 1 branch: no tree, no scratch, `CX(cell_0[i], dst[i])` for `i < W` — a fresh
`dst` is born ZERO so a ONE lane is Bennett's `NOTGate(data_out)` after the fold. The kernel
takes this branch without entering `cq_sandwich` (`cq_scratch_alloc(0)` is a hard error).

### 2.4 The index

Lanes `0 … n−1` of `idx` are read as controls and lanes `n … n_idx−1` are IGNORED
(`idx_full[1:n]`). `n_idx < n` is a hard error in both configurations, on Bennett's own
`error(...)` at `:172`. An index in `[count, Lp)` selects a padded leaf and reads 0. The
frozen ABI's contract is `idx ∈ [0, N)` with OOB undefined (CQ_lang `QramLowering.cpp:166`),
so truncation is a choice inside the contract.

## 3. Gate-count formula in W

At the all-quantum mask (every cell lane and every read index lane `CQ_BIT_Q`), `count ≥ 2`:

| | X | CX | CCX |
|---|---|---|---|
| tree, one half | 1 | 2·(Lp − 1) | Lp − 1 |
| copyout | 0 | 0 | count · W |
| **total (forward = `_unc`)** | **2** | **4·(Lp − 1)** | **2·(Lp − 1) + count · W** |

`count == 1`: `(0, W, 0)`.

The bead's "2(L−1) Toffoli" is the tree's row with `L = Lp`. The fan-out is NOT in Bennett's
count because Bennett's fan-out is CNOTs on constant data; it is `count · W` Toffolis here
because the data is quantum, and it folds back to Bennett's figure lane by lane wherever a
cell lane is constant.

**The composition check that reads no golden** (the K11 lesson): the suite measures the
tree block alone under a counting sink — `cq_qtree_steps(n)` gates through `cq_qtree_step`
on a scratch region — and pins `load = 2 × (that measurement) + (0, 0, count · W)`.

Corpus shape `(count, W) = (8, 32)`: `Lp = 8`, `(2, 28, 14 + 256) = (2, 28, 270)`, total 300.

## 4. Ancilla count

`2·Lp − 1` scratch qubits, all returned `|0⟩` by the reverse half, plus whatever `dst`
materialises. Bennett's DFS peaks at `2n + 1` (`:131`, "keeps wire count at O(log L)
peak") — see §5 delta 1. At the corpus shape: 15 here against 7 upstream.

## 5. Deltas from upstream

1. **FLAT schedule, not DFS — the qubit peak is `2·Lp − 1` instead of `2n + 1`.** Bennett
   computes two child flags, recurses, and uncomputes on the way back (`:120-129`),
   interleaving compute, fan-out and uncompute at every node. `cq_sandwich`'s shape is
   compute → copyout → reverse and cannot express that interleaving, and hand-writing the
   per-node uncompute inside a copyout is exactly the reverse pass Rule 8 forbids — it would
   also leave `CQ_ZERO_BY_PALINDROME` unfounded while every test stayed green. Gate count
   identical. Taken on D9's precedent (K12's flat scratch, chosen against measured
   alternatives); the DFS form is filed for v2.
2. **Toffoli fan-out on rail cells instead of data-dependent CNOTs on constants** — not a
   different construction but the same one read through the fold table (header note).
3. **Padded leaves are absent rather than zero-filled.** Bennett pads `data` with zero
   words (`:167`), whose leaves then emit no CNOT; our padded leaves own no cell and emit no
   Toffoli. Same gates, no padding storage.
4. **Rule 2's price is paid by the tree's reverse, which Bennett pays too** — this is one of
   the constructions that is already self-cleaning upstream, so unlike K10 there is no 2×
   here that Bennett does not also pay.

## 6. Confidence

**High** on the tree's three gates and their order (verbatim), the heap layout (a
transcription of `bit_level`), and the count. **High** on the fan-out's fold argument (the
§3 table is exhaustive at L0). The one thing only execution can settle is the BFS
parent-before-child order in step numbering, which `the_phase_boundaries_match_an_independent_slot_scan`'s
K12 shape is reused for: the suite re-derives the op-kind of every compute step from the
heap structure and compares it against the recorded stream.
