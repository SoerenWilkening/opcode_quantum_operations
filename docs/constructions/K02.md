# K02 — and

**Bennett source:** `third_party/bennett/src/lowering/arith.jl` lines 268-272 (pinned commit 980805de85314b3da7ac25cf6454b56566f8e609)
**libcqops module:** M10 `kernels/bitwise.c` (IMPLEMENTATION_PLAN.md:198)
**Clean or sandwich:** **clean** — no `cq_sandwich`, no scratch, no ancilla.

Why, and this is the question the task flagged as the trap: Bennett *does* write into an
allocated wire (`r = allocate!(wa, W)`, `arith.jl:269`), but that wire is **not scratch** —
it is the SSA result, and it is the only wire the function touches as a target. The body
contains no intermediate: `a[i] & b[i]` is produced in one `ToffoliGate` directly onto
`r[i]`, with `a` and `b` appearing only as controls. There is therefore no wire that
Bennett's *global* forward-copy-reverse wrap is cleaning up on this kernel's behalf, and
nothing for Bennett-in-the-small to localise. Substituting libcqops' caller-supplied `dst`
for `r` gives `dst ^= a & b` for an **arbitrary** initial `dst` — the Rule 7 contract
exactly — and the kernel is its own inverse, so `_unc` is a second call to the same
function.

The dirtiness worry is real for AND in general (an AND that had to *hold* its result
across a later step would leak), but it does not arise here: the AND is consumed
immediately by the XOR into `dst`.

## 1. Julia source excerpt

```julia
function lower_and!(g, wa, a, b, W)
    r = allocate!(wa, W)
    for i in 1:W; push!(g, ToffoliGate(a[i], b[i], r[i])); end
    return r
end
```

## 2. Gate sequence as indexed pseudo-code

```
kernel_and(ctx, dst, a, b, W):        /* dst ^= a & b */
    for s in [0, W):
        step(s):
            CCX(control1 = a[s], control2 = b[s], target = dst[s])
```

`n_compute = W`, one gate per step, no copy-out steps and no reverse half — driven by a
plain loop, **not** by `cq_sandwich`.

**I6 statement.** K02 never enters a `cq_sandwich` compute half, so **I6 is vacuous** —
there is no scratch extent for a target to be inside of. The property that does hold, and
that M10's test must assert:

> Every gate target is a bit of `dst`; `a` and `b` occur only as controls and are never
> materialised. Rule 8's `const cq_bit *` controls / `cq_bit *` target signature split
> makes the violation unconstructible.

Because of that, K02 is also safe to call **as a callee inside another kernel's sandwich
compute half** with `dst = scratch`: it then satisfies the caller's I6 automatically. This
matters — an AND-into-scratch is how K9 (cmp) and K12 (divrem) will use it.

## 3. Gate-count formula in W

Derivation: one loop, `for i in 1:W` (`arith.jl:270`), body pushes exactly one
`ToffoliGate` and nothing else. No `NOTGate` and no `CNOTGate` appear anywhere in the
function. Hence `W` Toffoli.

| Gate | Compute half | Sandwiched total (what libcqops emits) |
|---|---|---|
| NOT (X) | `0` | `0` |
| CNOT (CX) | `0` | `0` |
| Toffoli (CCX) | `W` | `W` |
| **Total** | **`W`** | **`W`** |

Identical columns **because K02 is clean**. (Counterfactual sandwich, for contrast only:
`2·W + W = 3W`, of which `W` would be CNOT copy-out. **Do not pin that as the L4 golden.**)

| W | X | CX | CCX | total |
|---|---|---|---|---|
| 1 | 0 | 0 | 1 | 1 |
| 8 | 0 | 0 | 8 | 8 |
| 16 | 0 | 0 | 16 | 16 |
| 32 | 0 | 0 | 32 | 32 |
| 64 | 0 | 0 | 64 | 64 |

At `ctx->ctrl_depth == 0`. K02 is the kernel where the controlled axis (Rule 9) hurts
most: every gate is already a Toffoli, and Bennett's promotion turns each one into three
Toffolis plus one shared ancilla —
`promote_gate!(out, g::ToffoliGate, ctrl, anc)` pushes
`ToffoliGate(ctrl, c1, anc)`, `ToffoliGate(anc, c2, target)`, `ToffoliGate(ctrl, c1, anc)`
(`third_party/bennett/src/controlled.jl:122-127`). So one level of control costs `3W`
Toffoli, a **3×** blow-up, versus 1× for a CX-only kernel. L4 goldens must record the
control depth they were pinned at.

## 4. Ancilla count

**0 ancillae, for every W.**

`lower_and!` calls `allocate!` once, for the result vector, which is libcqops' `dst` and
not an ancilla. No temporary is allocated, so nothing needs returning to `|0⟩` and Rule 2
is discharged trivially. Note that the *controlled* form is not ancilla-free — Bennett's
`promote_gate!` for Toffoli needs one shared ancilla, returned to `|0⟩` by the third gate
(`controlled.jl:122-127`) — but that ancilla belongs to the emitter's control stack
(plan §0.3), not to K02.

## 5. Deltas from upstream

1. **`dst` is a parameter, not an allocation.** Bennett allocates `r` (`arith.jl:269`);
   libcqops passes `dst` in (Rule 7). Same gate loop; different provenance of the target.
   That is what lets one function serve forward (`0 ^ f = f`) and uncompute (`f ^ f = 0`).
2. **Constant folding is per-bit here, per-operand upstream — and AND is where it pays
   most.** Bennett's identity peephole catches only whole-register constants:
   `op === :and && k == 0` returns fresh zero wires with no gates (`arith.jl:104-106`), and
   `op === :and && k == mask` degenerates to a copy (`arith.jl:121-129`). Anything in
   between falls through to `resolve!(::ConstOperand)`
   (`third_party/bennett/src/lowering/operand.jl:22-43`), which materialises the constant
   into `W` wires with one `NOTGate` per set bit, and then pays the full `W` Toffoli.
   libcqops' §3 fold table decides per bit: a `CCX` with a `BIT_ZERO` control emits
   **nothing**, and one with a `BIT_ONE` control folds to `CX`. The sharp case is
   `x & 0x0f` at W=8 — exactly the expression in Bennett's own `test/test_bitwise.jl:2`,
   and one the upstream peephole cannot fire on: Bennett pays 4 NOT + 8 Toffoli, libcqops
   pays 4 CX and **zero** Toffoli. **This is an L5 case, not an L4 golden**; pin the L4
   golden on all-quantum operands so it measures the kernel and not the fold table.
3. **Operand distinctness is asserted, not assumed (Rule 11 / D7) — and CCX makes it
   sharper than for xor.** `resolve!(::SSAOperand)` returns the *same* wire vector for the
   same SSA name (`operand.jl:3-20`), so upstream `x & x` emits
   `ToffoliGate(w, w, r)` with **coincident controls**. Bennett tolerates it (its
   simulator computes `b[c1] & b[c2]`, `simulator.jl:3`); libcqops must hard-error on
   `c1 == c2`, and equally on `dst` aliasing `a` or `b` — a target that is also a control
   destroys the "controls independent of target" property this kernel rests on.
4. **Wire reuse order differs, harmlessly.** Bennett's `allocate!` pops the minimum free
   wire (`wire_allocator.jl:19-22`); libcqops is LIFO (D4). K02 allocates no scratch, so
   this is inert here — noted only so nobody expects wire indices to match a Bennett trace.
5. **No global wrap to inherit.** Unlike the sandwich kernels, K02 takes no share of
   Bennett's top-level forward/copy/reverse, because it strands nothing.
