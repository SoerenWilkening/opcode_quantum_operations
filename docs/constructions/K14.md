# K14 — Shadow store at a quantum index (`cell[idx] := val`, old value onto ONE tape slot)

**Bennett source:** `third_party/bennett/src/shadow_memory.jl` lines 38-55 (`emit_shadow_store!`) and 98-121 (`emit_shadow_store_guarded!`), over K13's tree from `qrom.jl:87-133` (pinned commit 980805de85314b3da7ac25cf6454b56566f8e609)
**libcqops module:** M30 `kernels/qstore.[ch]` — v1.2, PRD §15 D24, plan §0.6, Step 27 (2026-09-02)
**Clean or sandwich:** **sandwich** for the tree, **in place** for the sweeps. **NOT a Rule 7 kernel** — K8/D17's shape, recorded against the rule's text below.

> **The shape, against Rule 7's text.** Rule 7 fixes `dst ^= f(sources)`, sources
> unchanged, ancillae back at `|0⟩`, and says a kernel departing from the parameter list
> must name every operand. K14 satisfies the THIRD clause only. It is `cell[idx] := val`
> with the displaced value moved onto a tape slot: the cells are written IN PLACE, the slot
> is written, and its inverse is the REVERSE CIRCUIT — the three sweeps in the opposite
> order — so a second call does not cancel (it would move `val` onto the slot and zero the
> cell). It may never be substituted for K13's shape; the forward value would be right and
> only the undo wrong, which is a silent miscompile rather than a test failure. It exists
> solely behind `cqrt_qram_store_*`, declares its own signature, and exports nothing a
> Rule 7 kernel could call by mistake. Like K8 it has **no L5**: a store into an
> all-classical array with a classical index is still a store, and the fold table prices it
> lane by lane rather than the kernel short-circuiting it.

## 1. Julia source excerpt

Verbatim, `third_party/bennett/src/shadow_memory.jl` lines 38-55:

```julia
function emit_shadow_store!(gates::Vector{ReversibleGate}, wa::WireAllocator,
                            primal::Vector{Int}, tape_slot::Vector{Int},
                            val::Vector{Int}, W::Int)
    length(primal)    == W || throw(DimensionMismatch("emit_shadow_store!: primal has $(length(primal)) wires, W=$W"))
    length(tape_slot) == W || throw(DimensionMismatch("emit_shadow_store!: tape_slot has $(length(tape_slot)) wires, W=$W"))
    length(val)       == W || throw(DimensionMismatch("emit_shadow_store!: val has $(length(val)) wires, W=$W"))

    for i in 1:W
        push!(gates, CNOTGate(primal[i], tape_slot[i]))
    end
    for i in 1:W
        push!(gates, CNOTGate(tape_slot[i], primal[i]))
    end
    for i in 1:W
        push!(gates, CNOTGate(val[i], primal[i]))
    end
    return nothing
end
```

The file's own header (lines 11-19) states the protocol and its reverse:

```
# Protocol per store (primal ← val, tape ← old primal):
#   1. CNOT primal[i] → tape[i]   (tape = old primal)
#   2. CNOT tape[i]   → primal[i] (primal = primal XOR tape = 0, since
#                                  tape currently equals primal)
#   3. CNOT val[i]    → primal[i] (primal = val)
#
# Bennett reverse unwinds this to primal = old, tape = 0.
```

## 2. Gate sequence as indexed pseudo-code

`count`, `n`, `Lp`, `W` and the flag region are K13's (K13.md §2); `T` is the ONE `W`-bit
tape slot, a rail born `|0⟩` at the push.

### 2.1 Compute half — K13's tree, unchanged (`cq_qtree_step`)

### 2.2 Copyout — the three guarded sweeps, `n_copyout = 3 · count · W`

Sweep-major, then cell, then lane: `s = sweep · (count · W) + j · W + i`.

```
sweep 0:   CCX(leaf_j, cell_j[i], T[i])          -- T       ^= leaf_j ∧ cell_j[i]   (T = old cell[idx])
sweep 1:   CCX(leaf_j, T[i],      cell_j[i])     -- cell_j  ^= leaf_j ∧ T[i]        (cell[idx] = 0)
sweep 2:   CCX(leaf_j, val[i],    cell_j[i])     -- cell_j  ^= leaf_j ∧ val[i]      (cell[idx] = val)
```

Each sweep is `emit_shadow_store_guarded!`'s corresponding Toffoli with `pred_wire = leaf_j`,
iterated over every cell. Because exactly one leaf is set, sweep 0 over ALL cells lands
exactly `cell[idx]` in `T`, sweep 1 clears exactly `cell[idx]`, sweep 2 writes exactly
`cell[idx]`; every other cell sees three Toffolis with a dead control.

**PUSH runs the copyout at `s = 0 … n_copyout−1`. POP runs it at `s = n_copyout−1 … 0`** —
the sweeps in the order 2, 1, 0 and within each sweep the cells and lanes in reverse (which
commute, but the driver-shaped reversal costs nothing). Each gate is its own inverse, so the
pop with the same operands restores every cell and returns `T` to `|0⟩`. Push and pop are
ONE step function and ONE sandwich call; the index map `s ↦ n_copyout − 1 − s` is the
entire difference.

### 2.3 `count == 1`

No tree: Bennett's unguarded `emit_shadow_store!` verbatim, `CX(cell_0[i], T[i])`,
`CX(T[i], cell_0[i])`, `CX(val[i], cell_0[i])`, without `cq_sandwich`; the pop is the same
three sweeps in reverse.

### 2.4 The index

As K13 §2.4. A padded index (`[count, Lp)`) sets a leaf that owns no cell: no sweep gate
fires, `T` stays `|0⟩`, and the pop is equally empty — consistent by construction.

## 3. Gate-count formula in W

At the all-quantum mask (every cell lane, every read index lane, every `val` lane `Q`),
`count ≥ 2`, push and pop alike:

| | X | CX | CCX |
|---|---|---|---|
| tree, both halves | 2 | 4·(Lp − 1) | 2·(Lp − 1) |
| three sweeps | 0 | 0 | 3 · count · W |
| **total** | **2** | **4·(Lp − 1)** | **2·(Lp − 1) + 3 · count · W** |

`count == 1`: `(0, 3W, 0)` — Bennett's "3W CNOTs per store, zero Toffolis"
(`shadow_memory.jl:10`).

**The composition check that reads no golden**: `push = 2 × tree + (0, 0, 3 · count · W)`
with the tree measured through K13's exported block.

Corpus shape `(8, 32)`: `(2, 28, 14 + 768) = (2, 28, 782)`, total 812.

**Under a quantum `pred`** (Rule 9, M06): `(x, cx, ccx) → (0, x, cx + 3·ccx)`, i.e.
`(0, 2, 28 + 3·782) = (0, 2, 2374)` at the corpus shape. D24 records the root-flag guard
that would make it `(0, 29, 782)` and rejects it for v1.2.

## 4. Ancilla count

The tree's `2·Lp − 1`, returned by the reverse half; plus the tape slot `T` — `W` qubits at
most, materialised lane by lane as sweep 0 finds a non-ZERO cell lane — which is NOT an
ancilla: it is a rail the shim owns until the pop, and its release is D15's certificate's
business, never a `proven_zero` literal (PRD §15 D24 (c)). Upstream's `shadow_checkpoint`
would take `count · W` (CQ_lang PRD-7.5 §2.4) — §5 delta 1.

## 5. Deltas from upstream

1. **ONE tape slot per store instead of one per cell.** Upstream checkpoints every slot and
   guards each with its own equality wire; under unary iteration exactly one leaf is set,
   so the XOR of the per-cell slots is a single `W`-bit rail. `W` qubits per store instead
   of `count · W`; `3 · count · W` Toffolis either way.
2. **The equality wires are the tree's leaves**, `2·(Lp − 1)` Toffolis for all of them,
   rather than `count` separate constant comparators — Rule 1 applied to the call graph:
   K14 calls K13's exported block and transcribes no tree of its own.
3. **The guard is per gate, as upstream's; the CONTROLLED store is M06's promotion of that,
   not a second guard.** `cqrt_qram_store_<W>_controlled(pred, …)` runs the same kernel
   inside `cq_shim_region(pred)` (Rule 9), which lifts every Toffoli to three. The cheaper
   root-flag spelling is recorded in D24 and rejected.
4. **Not sandwiched as a whole** — D17's argument for `addc`: Rule 8's driver replays its
   compute half, and replaying the sweeps would undo the in-place write. The TREE is
   sandwiched; the sweeps are the copyout, which the driver runs once.

## 6. Confidence

**High** on the three sweeps (verbatim, per lane) and on the single-slot argument (it is the
unary-iteration invariant, which K13's L1 already pins: exactly one leaf reads as set). The
L3 restatement — pop restores every cell and `T == 0` — is what execution must settle, and
it is asserted on VALUES through the shadow at every mask (Rule 14: never on kinds).
