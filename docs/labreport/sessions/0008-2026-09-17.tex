\field{The ask}

\bead{09z}, \bead{ta1}, \bead{6q4}, \bead{qki} --- as one batch of worktree agents, with a

the pair it describes, not a task.

\field{What landed}
\texttt{tests/support/childcap.c}'s two pipes are drained \emph{concurrently} through
\texttt{poll()}, and a full buffer no longer ends a drain --- past the cap the bytes are read
and dropped, so the stored prefix is byte-for-byte what the sequential shape stored while the
child always gets to finish. The counter-intuitive half of \bead{ta1} is now executable rather
than argued: a \emph{small} capture buffer made the old hazard worse, not safer.

A new \texttt{tests/test\_childcap\_controls.inc} carries six cases. Being an \texttt{.inc} it
registers no ctest entry and is outside \texttt{check\_loc.sh}'s extension walk, so
\texttt{tests/CMakeLists.txt} was untouched by either agent and the sorted \texttt{ctest -N}
diff is empty in both configurations. What closed \bead{09z} was not an assertion but a
\emph{wider corpus of children}: every child the tree forked before today either aborted or
returned, so four different weakenings of the SIGABRT test agreed with the real predicate on
every input it was ever given. A child that prints and \texttt{\_Exit(1)}s, and one that prints
and raises \texttt{SIGTERM}, are what make them disagree.

\texttt{test\_kernel\_shift\_var.c}'s purpose-built pool assertion now runs first, ahead of the
sweep whose incidental \texttt{W=1} span underflow used to abort the process before it.
\texttt{shim/cq\_runtime\_v2.c}'s running count is appended rather than corrected, and carries
the instruction to read the population from \texttt{CQ\_V2\_N\_THUNKS} and never from a comment.
