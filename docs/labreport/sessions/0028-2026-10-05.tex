\field{The ask}
Same session, after entry~27's commit (\texttt{cf5185a}): \bead{7s60}, run
alone, which was to profile the Debug poles and decide whether to split
them. Midway through, the maintainer ruled that slow test runs are
unacceptable as such, which turned the work into \bead{y65c}. The generated
range and bead lists repeat entry~27's, because that entry was captured
before its own commit; this entry covers only the work after
\texttt{cf5185a}.

\field{What landed}
The fp and \texttt{ibits} step machines no longer redo program-sized work on
every gate. Each program's prefix offsets and slot starts are built once per
program, or once per kernel call, and a step finds its row by binary search.
Each block's base is added at exactly one site per module. The per-lane view
copies are now one shared routine. Every emitted gate is unchanged. A stale
comment in the fadd suite's two-blocks case now names the new
offset site, with a dated note.
