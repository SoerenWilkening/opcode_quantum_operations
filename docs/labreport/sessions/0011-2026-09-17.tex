\field{What landed}
\textbf{L6 no longer aborts, so NORTH\_STAR finish-line condition~1 is met for the first
time.} The one fixture that aborted,
\texttt{e2e-slice-loop-pairing-measure-owned}, did so on a \emph{second}
\texttt{cqrt\_measure} of one handle, and that turns out to be legal on the frozen ABI ---
CQ\_lang's own committed golden emits it twice, its loop pass is written to expect plural
measure users, and its post-measure reject explicitly \emph{excludes} measure sinks from the
user set it scans. \texttt{cq\_reg\_mark\_measured} is now idempotent on
\texttt{CQ\_SLOT\_MEASURED} in one line; \texttt{DEAD}, \texttt{TOKEN}, poison, the write door
and \texttt{cq\_reg\_free} all still refuse. Two death cases became \emph{positive} exemption
cases, since a refusal's permitted direction needs its own fixture.

described moved underneath it. \texttt{childcap.c}'s EINTR retry count is now measured at
configure time and \texttt{\_Static\_assert}ed, so a fourth site breaks the build.
\texttt{gen\_data.py}'s \texttt{scratch.dat} provenance line now names the archive's mtime and
says the SHA dates the \emph{run}. M12's three entry points carry a note recording that they
are rows of a dispatch table, which a symbol grep cannot follow.
