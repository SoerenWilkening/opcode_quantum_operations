\field{The ask}
Explain why the bounded floating-point tests were still slow, then make
\texttt{fadd}, \texttt{fmul}, \texttt{fconv}, and \texttt{fdiv} fast without
weakening their representative-value coverage.

\field{What landed}
The four table-driven families now prepare immutable row, bit-offset, and slot
prefix metadata once.  Per-slot dispatch uses a last-boundary binary search,
which preserves the ownership rule at duplicate boundaries created by
zero-slot view rows.  Whole-kernel calls rebase offsets once before the
compute/uncompute sandwich; public standalone step blocks retain their
defensive per-call fit check and rebase.  Operands and circuit state are never
cached.  Each suite has a linear-oracle check of the cached map at every slot,
while the existing two-block cases continue to cover nonzero region offsets.

\field{Not taken}

more expensive under ASan/UBSan, while all four affected Debug targets did
compile and link.
