# Depth tables

Generated by `tools/depth_table` from `src/kernels/registry.c`; do not edit. Regenerate this file and `src/kernels/kernel_choice.c` with `cmake --build <build> --target depth_tables`; the `depth` test fails while either is stale.

**How to add a candidate:** write `void k(int32_t o, const int32_t *args, uint32_t w)` (o ^= f(args)) in `src/kernels/`, declare it in `kernels.h`, add `{ "name", k, NULL, "source" }` to its operation's list in `registry.c`, regenerate. A new operation also needs one enum line in `kernels.h`, one entry in `cq_kernel_ops`, and its reference function in `tools/depth.c`.

Rule (NORTH_STAR, Depth first): per (operation, width) the least depth ships; ties go to fewer qubits, then fewer gates, then registration order. Cells are depth / gates / qubits of the operation alone, all operands forced to qubits, from the replay backend through the sampled harness (`hx_run`); **bold** is shipped; FAIL failed its sampled check and is never shipped.
